Lista de tarefas:

Player:
fazer espadada
fazer atirar com arco

Enemy:
fazer disparo

Object:
fazer baú (compra flechas)
fazer kitmédico (restaura 1 hp)
fazer espada no chão comprável (desabilita modo soco, habilita modo espadada)
fazer arco no chão comprável (habilita modo arco)

Gameplay:
fazer combate
fazer capitalização (matar inimigos dá dinheiro, dinheiro compra objetos)
fazer limite de inimigos que aumente com o nível (inicia em 2, sempre 1 ghost garantido)
fazer progressão de niveis (nível 1: Velocidade padrão, limite 2. += 1 em ambos para nivel 2) a cada x inimigos mortos, aumenta um nível.
fazer score (matar inimigos gera pontos, quantidade aumenta conforme o nível), vidas, dinheiro, flechas

Assets:
fazer OST
fazer efeitos sonoros
fazer animações do player de acordo com armas selecionadas
fazer animação de combate player
fazer sprites de projeteis
fazer animações de andar, spawnar (mago) e ficar parado
